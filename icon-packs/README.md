# Icon packs

No decorative packs are bundled. Windows icons are the default; individually selected PNG/ICO files and user-imported packs remain supported.
Runtime packs live in `%LOCALAPPDATA%\FloatingDock\IconPacks`.
`Default` is the system-icon fallback and `Custom` is an empty folder for your own images.

Full format and matching rules: [../docs/ICON-PACKS.md](../docs/ICON-PACKS.md).
