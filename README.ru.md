<h1 align="center">FloatingDock</h1>
<p align="center">Плавающий док, Launchpad и стеклянная верхняя панель для Windows.</p>
<p align="center"><a href="README.md">English</a> · <strong>Русский</strong></p>

FloatingDock — компактный интерфейс рабочего стола с плавным увеличением иконок, поиском приложений, живыми превью окон и скруглённой верхней панелью. Самостоятельное приложение на C# / WinUI 3 с настройками расположения, пользовательскими иконками и тёмными стеклянными поверхностями.

## Возможности

- **Док под твой рабочий стол.** Расположение снизу, слева или справа; настройка размеров иконок, расстояний, выравнивания и отступов.
- **Плавное взаимодействие.** Увеличение иконок, индикаторы приложений, перетаскивание, появление и скрытие. Панели скрываются при fullscreen-видео и выделении области скриншота.
- **Закреплённые и запущенные приложения.** Запуск, переключение и сворачивание из одной панели. Вспомогательные окна Steam объединяются с основным клиентом.
- **Живые превью.** Наведение на 750 мс открывает миниатюру; клик переключает на окно, крестик закрывает его. Превью плавно исчезает перед обычной командой закрытия.
- **Launchpad.** Закрепления «Пуска» и приложения, добавленные кнопкой «+» или перетаскиванием ярлыка. Три варианта иконки лаунчпада.
- **Верхняя панель.** Активное приложение, сеть, громкость, язык ввода, батарея при наличии, часы и календарь. Доступны автоскрытие и резервирование места для окон. Управление воспроизведением, собственное меню настоящих значков трея Windows и общий поиск; отдельные FPS и длительности скрытия.
- **Свои иконки.** PNG/ICO и импорт ZIP-паков для дока и Launchpad. Декоративных предустановленных паков нет.
- **Блюр внутри приложения.** Размытие не зависит от переключателя прозрачности Windows; переходы учитывают системную настройку анимаций.
- **Управление панелью задач.** Оставить панель Windows, включить автоскрытие или скрыть полностью; исходное состояние записывается для восстановления.

Настройки по умолчанию на английском; русский выбирается в Settings → Appearance → Interface language. Поиск приложений и личных файлов работает по Рабочему столу и Загрузкам; папки и глубина меняются в Settings → Search. Documents исключена. Кеш имён обновляется раз в 30 секунд; время обхода и число записей ограничены.

## Скачать и запустить

Актуальная сборка Windows x64 доступна в [Releases](https://github.com/melloghh/FloatingDock/releases/latest).

| Пакет | Как использовать |
|---|---|
| `FloatingDock-Setup-x64.exe` | Установка для текущего пользователя; можно добавить ярлык рабочего стола и автозапуск. |
| `FloatingDock-Portable-x64.zip` | Распакуй **весь архив** и запусти `FloatingDock.exe`. EXE должен оставаться рядом с DLL и ресурсами. |

Релиз включает .NET и Windows App SDK: отдельно устанавливать runtime не нужно. Требуется Windows x64; проект ориентирован на Windows 10 1809 и новее, локальные проверки выполнены на Windows 11. Сборки пока не подписаны, поэтому Windows может показать предупреждение SmartScreen.

## Быстрые действия

| Действие | Управление |
|---|---|
| Открыть Launchpad | Иконка запуска в доке или `Ctrl+Alt+Space` |
| Поиск приложений и файлов | `Ctrl+Alt+K` или значок поиска верхней панели |
| Фокус клавиатуры в доке | `Ctrl+Alt+D`, затем стрелки, Enter и Esc |
| Открыть настройки | Контекстное меню дока/трея или шестерёнка верхней панели |
| Поменять расположение дока | Settings → Dock |
| Настроить верхнюю панель | Settings → Menu Bar |
| Заменить иконку | Правый клик → Change icon |
| Импортировать набор иконок | Settings → Icon Packs → Import ZIP |
| Восстановить панель задач | `Ctrl+Alt+Shift+T` или меню трея |

Настройки, закрепления, иконки и логи хранятся в `%LOCALAPPDATA%\FloatingDock`, в том числе у portable. Обновления сохраняют эти данные.

Если приложение принудительно завершили и панель задач осталась скрыта, используй установленный ярлык восстановления панели или команду:

```powershell
.\FloatingDock.exe --restore-taskbar
```

Не удаляй `taskbar-state.json`, пока восстановление не завершится успешно. Режим **Hide completely** скрывает исходную панель задач. Стрелка верхней панели открывает настоящий список скрытых значков Explorer на поддерживаемых версиях оболочки; **Leave** сохраняет обычную панель задач. Управление музыкой требует поддержки Windows media session со стороны приложения.

Поиск Wi-Fi подчиняется разрешениям Windows. Для списка ближайших сетей система может потребовать доступ к местоположению; FloatingDock это ограничение не обходит.

## Сборка из исходников

Нужны Windows x64 и .NET SDK из [global.json](global.json): 10.0.401 или совместимый patch. Inno Setup 6.6.1 нужен только для установщика; `ISCC.exe` должен быть доступен через `PATH`.

```powershell
git clone https://github.com/melloghh/FloatingDock.git
cd FloatingDock
dotnet restore FloatingDock.sln -p:Platform=x64
dotnet build FloatingDock.sln -c Release -p:Platform=x64 --no-restore
dotnet test FloatingDock.sln -c Release -p:Platform=x64 --no-build
.\packaging\publish.ps1 -Zip -Installer -SkipTests
```

Результат появляется в `artifacts/`. Убери `-Installer`, если нужна только portable. Скрипт проверяет runtime и ресурсы и создаёт SHA-256. `-SmokeTest` добавляет проверку интерфейса; для неё нужна интерактивная сессия Windows.

GitHub Actions собирает и тестирует Windows x64 и сохраняет portable и установщик как артефакты workflow. Проверки настоящих окон выполняются отдельно: сборка CI сама по себе не проверяет fullscreen и наведение.

## Структура проекта

| Папка | Содержимое |
|---|---|
| `src/FloatingDock.Core` | Раскладка, анимации, сопоставление приложений, сохранение данных и логика паков |
| `src/FloatingDock.Windows` | Windows API, оболочка, отслеживание окон и восстановление панели задач |
| `src/FloatingDock.App` | WinUI-интерфейс, док, Launchpad, настройки и верхняя панель |
| `tests` | Тесты Core и Windows-интеграции |
| `packaging` | Portable и установщик Inno Setup |

Подробнее: [архитектура](docs/ARCHITECTURE.md), [формат паков](docs/ICON-PACKS.md), [история изменений](docs/CHANGELOG.md).

Версия **1.2.0** сохраняет исправления геометрии и размытия из 1.0.17–1.0.19 и добавляет проверки новых функций. Трей использует доступность Explorer и PNG-снимки значков Windows; снимки могут запаздывать при смене состояния значка. Проверки нескольких физических мониторов и сочетаний DPI ограничены.

Собственный тайлинг включается в Settings → Tiling manager. Раскладка, рабочие пространства, управление с клавиатуры, свободные окна, исключения и восстановление позиций описаны в [документации тайлинга](docs/TILING.md). Отдельная программа не требуется.
