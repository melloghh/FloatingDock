<h1 align="center">FloatingDock</h1>
<p align="center">Плавающий док, Launchpad и стеклянная верхняя панель для Windows.</p>
<p align="center"><a href="README.md">English</a> · <strong>Русский</strong></p>

FloatingDock — компактный интерфейс рабочего стола с плавным увеличением иконок, поиском приложений, живыми превью окон и скруглённой верхней панелью. Системная часть — небольшой нативный движок на Rust, интерфейс написан на Flutter (Material 3). Расположение, иконки и цвета настраиваются.

## Возможности

- **Док под твой рабочий стол.** Расположение снизу, слева или справа; настройка размеров иконок, расстояний, выравнивания и отступов.
- **Плавное взаимодействие.** Увеличение иконок, индикаторы приложений, перетаскивание, появление и скрытие. Панели скрываются при fullscreen-видео и остаются доступными при создании скриншота.
- **Закреплённые и запущенные приложения.** Запуск, переключение и сворачивание из одной панели. Вспомогательные окна Steam объединяются с основным клиентом.
- **Живые превью.** Наведение на 750 мс открывает миниатюру; клик переключает на окно, крестик закрывает его. Превью плавно исчезает перед обычной командой закрытия.
- **Launchpad.** Закрепления «Пуска» и приложения, добавленные кнопкой «+» или перетаскиванием ярлыка. Три варианта иконки лаунчпада.
- **Верхняя панель.** Активное приложение, сеть, громкость, язык ввода, батарея при наличии, часы и календарь. Доступны автоскрытие и резервирование места для окон. Управление воспроизведением, собственное меню настоящих значков трея Windows и общий поиск; отдельные FPS и длительности скрытия.
- **Свои иконки.** PNG/ICO и импорт ZIP-паков для дока и Launchpad. Декоративных предустановленных паков нет.
- **Блюр внутри приложения.** Размытие не зависит от переключателя прозрачности Windows; переходы учитывают системную настройку анимаций.
- **Управление панелью задач.** Оставить панель Windows, включить автоскрытие или скрыть полностью; исходное состояние записывается для восстановления.

Настройки по умолчанию на английском; русский выбирается в Settings → Appearance → Interface language. Поиск приложений и личных файлов работает по Рабочему столу и Загрузкам; папки и глубина меняются в Settings → Search. Documents исключена. Кеш имён обновляется раз в 30 секунд; время обхода и число записей ограничены.

## Скачать и запустить

Актуальная сборка Windows x64 доступна в [Releases](https://github.com/melloghh/FloatingDock/releases/latest).

| Пакет | Как использовать |
|---|---|
| [FloatingDock-Setup-x64.exe](https://github.com/melloghh/FloatingDock/releases/latest/download/FloatingDock-Setup-x64.exe) | Установка для текущего пользователя; можно добавить ярлык рабочего стола и автозапуск. |
| [FloatingDock-Portable-x64.zip](https://github.com/melloghh/FloatingDock/releases/latest/download/FloatingDock-Portable-x64.zip) | Распакуй **весь архив** и запусти `FloatingDock.exe`. EXE должен оставаться рядом с DLL и ресурсами. |

Релиз включает .NET и Windows App SDK: отдельно устанавливать runtime не нужно. Требуется Windows x64; проект ориентирован на Windows 10 1809 и новее, локальные проверки выполнены на Windows 11. Сборки пока не подписаны, поэтому Windows может показать предупреждение SmartScreen.

Настройки FloatingDock открываются через главное меню или контекстное меню дока/трея. Шестерёнка верхней панели открывает параметры Windows. Поиск сначала пустой, затем предлагает часто открываемые через него приложения; системный мусор Windows отфильтрован. В релизе есть `SHA256SUMS.txt` и лицензии включённых компонентов.

## Быстрые действия

Поиск, быстрые меню, Launchpad и настройки используют общий полупрозрачный стеклянный материал. В Launchpad и главном меню есть **Выключить** и **Перезагрузить** с подтверждением; по умолчанию выбрана отмена. Распознанная системная кнопка «—» и клик в доке используют одну анимацию к значку, восстановление из дока — обратную. Для нестандартных кнопок, прямых системных команд и недоступных окон остаётся системный вариант. Новые окна, запущенные через FloatingDock, плавно появляются после стабилизации начального размера. Настройки анимаций учитываются.

Поверхность трея появляется сразу, пока Explorer возвращает значки. Свежий список повторно используется до пяти секунд; при клике цель всё равно проверяется заново. Маленькие изображения уведомлений показываются в исходном разрешении без размытого увеличения, с сохранением их состояния. Доступная детализация зависит от изображения Windows или приложения.

| Действие | Управление |
|---|---|
| Открыть Launchpad | Иконка запуска в доке или `Ctrl+Alt+Space` |
| Поиск приложений и файлов | `Ctrl+Alt+K` или значок поиска верхней панели |
| Фокус клавиатуры в доке | `Ctrl+Alt+D`, затем стрелки, Enter и Esc |
| Открыть настройки FloatingDock | Главное меню или контекстное меню дока/трея |
| Открыть параметры Windows | Шестерёнка верхней панели |
| Поменять расположение дока | Settings → Dock |
| Настроить верхнюю панель | Settings → Menu Bar |
| Заменить иконку | Правый клик → Change icon |
| Импортировать набор иконок | Settings → Icon Packs → Import ZIP |
| Восстановить панель задач | `Ctrl+Alt+Shift+T` или меню трея |

Настройки, закрепления, иконки и логи хранятся в `%LOCALAPPDATA%\FloatingDock`, в том числе у portable. Обновления сохраняют эти данные.

Если приложение принудительно завершили и панель задач осталась скрыта, используй установленный ярлык восстановления панели или команду:

```powershell
.\FloatingDock.exe --restore-taskbar
```

Не удаляй `taskbar-state.json`, пока восстановление не завершится успешно. Режим **Hide completely** скрывает исходную панель задач. Стрелка верхней панели открывает собственное меню FloatingDock со значками Windows; **Leave** сохраняет обычную панель задач. Управление музыкой требует поддержки Windows media session со стороны приложения.

Поиск Wi-Fi подчиняется разрешениям Windows. Для списка ближайших сетей система может потребовать доступ к местоположению; FloatingDock это ограничение не обходит.

## Сборка из исходников

Нужны Windows x64, Rust (stable, MSVC) и для интерфейса Flutter. Inno Setup 6 нужен только для установщика.

```powershell
git clone https://github.com/melloghh/FloatingDock.git
cd FloatingDock\rust
cargo test --workspace
cargo build --release -p fd-engine          # rust\target\release\fd-engine.exe
cd ..\ui_flutter\app
flutter build windows --release --no-tree-shake-icons
cd ..\..
.\packaging\release-rust.ps1 -Out ..\release -Ui ui_flutter\app\build\windows\x64\runner\Release
```

`release-rust.ps1` собирает portable-папку (`FloatingDock.exe` — это движок, он сам запускает `ui\fd_ui.exe`), zip, установщик и `SHA256SUMS.txt`. GitHub Actions гоняет тесты Rust и собирает движок; релиз собирается и публикуется вручную. Версии до 1.6.6 были приложением на C# / WinUI 3: смотри тег `v1.6.6`.

## Структура проекта

| Папка | Содержимое |
|---|---|
| `rust` | Движок: `fd-core` (настройки, приложения, иконки, поиск, безопасность панели задач), `fd-ipc` (протокол), `fd-windows` (Win32), `fd-engine` (программа) |
| `ui_flutter` | Интерфейс (Flutter) и Dart-клиент протокола движка |
| `assets` | Иконка приложения и картинки |
| `packaging` | Скрипт релиза, установщик Inno Setup, файлы портативной сборки |

Подробнее: [архитектура](docs/ARCHITECTURE.md), [формат паков](docs/ICON-PACKS.md), [история изменений](docs/CHANGELOG.md).

История версий и отдельных исправлений записана в [журнале изменений](docs/CHANGELOG.md). Проверены собственные диагностические окна и настоящий Zen. Трей использует доступность Explorer и PNG-снимки значков Windows; снимки могут запаздывать при смене состояния значка. Проверки нескольких физических мониторов и сочетаний DPI ограничены.

Сообщить об ошибке можно через [GitHub Issues](https://github.com/melloghh/FloatingDock/issues/new/choose): укажи версию приложения, Windows, масштаб экрана и шаги воспроизведения.
